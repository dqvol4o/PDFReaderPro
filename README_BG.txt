PDF Reader Pro v0.3 - тестов прототип
====================================
Това е изходен проект с автоматична компилация в GitHub Actions.

За готов EXE без инсталиране на компилатор:
1. Създайте ново хранилище в github.com (може да е private).
2. Качете файловете от тази папка, включително .github/workflows/windows.yml.
   В GitHub: Add file -> Upload files; за скритата .github папка е удобно
   да използвате Create new file и да въведете .github/workflows/windows.yml.
3. Отворете Actions -> Build portable PDF Reader Pro -> Run workflow.
4. След успешно изпълнение изтеглете ZIP от Artifacts (x64 или x86).
5. Разархивирайте и стартирайте PDFReaderPro.exe.
   PDFReaderPro.exe и pdfium.dll трябва да са в една папка.

Ограничения: Това е прототип, не окончателен продукт. Има отваряне,
прелистване и мащабиране. Няма още раздели, търсене и печат.
Възможни са проблеми при големи страници и някои PDF файлове.
Не е изпълняван Windows тест в тази среда.
